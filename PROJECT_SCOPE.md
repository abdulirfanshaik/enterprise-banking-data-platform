# Project scope and provenance

## Built in this portfolio project

- Synthetic source generation
- Local Bronze/Silver/Gold implementation
- Canonical payment model
- Data-quality quarantine and thresholds
- Settlement reconciliation
- Rule-based alert candidates
- Customer 360 and regulatory-style daily marts
- SQLite analytical database
- Kafka/PySpark/Airflow/dbt/Terraform/CI examples
- Tests and runbooks

## Not claimed

- Access to an employer's internal data, schemas, repositories, or infrastructure
- A real Finacle export
- Actual RBI filing logic or NPCI customer-level data
- Production fraud-model ownership
- Employer transaction volumes, cluster sizes, topic names, or incident details
- That every enterprise example was deployed to a paid cloud account

## Naming convention

All generated source systems use `SIMULATED_*` names in the canonical data. This
is deliberate evidence that the repository is a portfolio implementation.
